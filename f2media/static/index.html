解析媒体

这里只解析并展示媒体信息，不会下载媒体或创建最终作品目录。确认后再下载到 NAS。

临时指定解析器只影响本次解析，不会修改全局路由。

最近任务

删除任务记录不会删除已下载媒体。

Cookie

支持 Netscape cookies.txt 或 Cookie Header。Cookie 内容加密保存，不会回显到页面和日志。

平台解析路由

每个平台都显示全部解析器。拖动或使用 ↑ / ↓ 调整顺序；关闭的解析器会被跳过。标记“推荐”的解析器是该平台默认启用项。

在线解析引擎

更新前先下载到临时目录并运行 --version 自检，成功后原子替换；上一版本保留用于一键回滚。

免费解析 API

实际顺序：本地解析 → 免费 API（按优先级逐个尝试）→ gallery-dl → yt-dlp。接口失效时直接编辑或新增即可。
